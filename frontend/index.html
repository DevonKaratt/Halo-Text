What HALO can do

Screen translation

Drag around text to show the translation in the same area. English OCR is built in; install an optional OCR pack for other supported scripts.

Live captions

Faster captions mode keeps checking a selected part of a video for new dialogue, including Russian captions when the Cyrillic OCR pack is installed.

53 output choices

Choose English or an Indian or global output language from the floating H menu. Available downloaded pairs can run offline.

Spoken translation

English audio can be recognized and spoken in the selected language with available voices.

How to use it

  1. Read the manual, unzip to a writable folder, and double-click HaloText.exe.
  2. Right-click the floating blue H and choose an output language. For non-English input, download the appropriate Input OCR language pack. No optional language or speech pack comes preinstalled.
  3. Press Ctrl+Alt+R, drag around the text or captions, and release. If HALO detects another source language, choose online translation or download an available offline pair.
  4. Use Ctrl+Alt+A to pause, or Ctrl+Alt+C to clear the box.

HALO runs in the background. Double-click H to select another area. The full shortcut list is in the H menu.

Privacy and practical limits

Installed OCR and translation packs process text on your computer. The online route sends recognized text to Google Translate only after you choose it for a detected non-English source; it does not send screenshots. Online speech sends translated text to Microsoft's speech service. OCR pack availability, short-text detection, network response, and screen content affect coverage and speed. The current OCR catalogue does not include every writing system.

Get HALO for Windows

Portable 64-bit Windows package with no preinstalled language or speech models. Unzip to a writable folder, double-click HaloText.exe, then right-click H. Choose a language and download its offline model if available. See the included manual.
